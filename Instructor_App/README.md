# Skillora Instructor Studio — Flutter Mobile Application

Skillora Instructor Studio is an educator and course creator Flutter mobile application template built with GetX state management and Flutter 3.

## Key Features
- **Executive Analytics:** Live earnings metrics, active student counts, and ratings overview.
- **Course Studio & Curriculum Builder:** Multi-step wizard to create courses, organize modules, and upload video lessons.
- **Q&A Resolution Hub:** Filter unanswered questions and dispatch verified educator responses.
- **Digital Signature Studio:** Register stylized script signatures or upload PNG signatures for student certificates.
- **Wallet & Payouts:** Track lifetime revenue, available balance, and withdrawal requests.
- **Demo Login:** Quick auto-fill button on sign-in screen for instant testing.

## Getting Started

### Prerequisites
- Flutter SDK >= 3.24.0
- Dart SDK >= 3.5.0
- Java JDK 17

### Installation
1. Install dependencies:
   ```bash
   flutter pub get
   ```
2. Run on emulator or device:
   ```bash
   flutter run
   ```
