# Skillora Student App — Flutter Mobile Application

Skillora is an online learning and video course Flutter mobile application template built with clean GetX state management and Flutter 3.

## Key Features
- **Course Catalog & Search:** Explore categories, filter courses, and view trending lectures.
- **Video Lecture Player:** HD video streaming with playback speed control and landscape view.
- **Lesson Progress Checklist:** Interactive checkboxes with real-time recalculation of course completion percentage.
- **In-Course Q&A:** Lecture discussion community with instructor response badges.
- **Instructor Profiles:** Mentor bios, course listings, and reactive follow counter.
- **Verifiable Digital Certificate:** Auto-unlocked upon 100% course completion.
- **Payment Ready:** Built-in Stripe checkout sheet integration.
- **Multi-Language Support:** English, Hindi, Gujarati, Italian, and Chinese.

## Getting Started

### Prerequisites
- Flutter SDK >= 3.24.0
- Dart SDK >= 3.5.0
- Java JDK 17

### Installation
1. Install dependencies:
   ```bash
   flutter pub get
   ```
2. Run on emulator or device:
   ```bash
   flutter run
   ```
