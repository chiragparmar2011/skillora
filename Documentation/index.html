Digital Certificate & Signature Integration

How the Instructor's digital signature links directly to the Student's course completion certificate.

One of Skillora's standout commercial features is its verifiable certificate ecosystem:

1

Instructor Configures Digital Signature

In the Instructor App (under Profile → Digital Signature), the teacher selects their preferred stylized script font or uploads a PNG signature.

2

Student Completes Course

Once all lessons in a course are marked complete (100% progress), the student receives the "Claim Certificate" prompt.

3

Certificate Rendering & Stamping

The certificate dialog renders the student name, course title, completion date, unique serial code, and the instructor's digital signature.

Change App Name & Package ID

Crucial steps before publishing to Google Play Store and Apple App Store.

1

Change Android Package Name

Open android/app/build.gradle in each app and update applicationId:

Groovy (build.gradle)
defaultConfig {
    // Replace with your company reverse domain
    applicationId "com.yourcompany.skillorastudent"
    minSdkVersion 21
    targetSdkVersion 34
    versionCode flutterVersionCode.toInteger()
    versionName flutterVersionName
}
2

Change iOS Bundle Identifier

Open the project in Xcode (ios/Runner.xcworkspace) or edit ios/Runner.xcodeproj/project.pbxproj to change PRODUCT_BUNDLE_IDENTIFIER to your custom identifier.

3

Change App Display Name

Android: Edit android/app/src/main/AndroidManifest.xml → android:label="Your App Name".
iOS: Edit ios/Runner/Info.plist → <key>CFBundleDisplayName</key> <string>Your App Name</string>.

Multi-Language & RTL Support

Skillora comes pre-configured with 5 languages: English, Hindi, Gujarati, Italian, and Chinese.

Translation JSON files are located in assets/json/:

  • en.json — English (Default)
  • hi.json — Hindi
  • ar.json — Arabic (Right-to-Left Layout automatically applied)

To add a new language (e.g. Spanish - es.json):

  1. Create assets/json/es.json with translated keys.
  2. Declare it in pubspec.yaml under assets:.
  3. Add Locale('es', 'ES') to lib/translation/localization_delegates.dart.

Backend & API Integration

Clean architecture ready for Laravel, Node.js, Firebase, or Supabase.

All HTTP requests and service communication are organized in the lib/services/ directory. Simply update url_endpoints.dart with your backend base URL:

Dart (url_endpoints.dart) 
class UrlEndpoints {
  // Replace with your live REST API server URL
  static const String baseUrl = "https://api.yourdomain.com/api/v1/";
  
  static const String login = "${baseUrl}auth/login";
  static const String courses = "${baseUrl}courses";
  static const String questions = "${baseUrl}courses/qa";
  static const String reviews = "${baseUrl}courses/reviews";
  static const String payouts = "${baseUrl}instructor/payouts";
}

Build Android AppBundle (Google Play)

Generate release production binaries for the Google Play Store.

1

Generate Keystore File

Terminal
keytool -genkey -v -keystore ~/upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
2

Create key.properties

Create android/key.properties with your keystore path and passwords.

3

Compile Release AppBundle

Terminal
flutter build appbundle --release

Output file: build/app/outputs/bundle/release/app-release.aab

Build iOS (Apple App Store)

Generate production iOS builds using Xcode or terminal.

Terminal 
flutter build ipa --release

Open build/ios/archive/Runner.xcarchive in Xcode Organizer to validate and upload directly to App Store Connect.

Troubleshooting & FAQ

Quick solutions to the most common setup questions.

Q: Gradle build error: "Unsupported class file major version"

Solution: Ensure your system is using Java JDK 17. Run java -version to verify. Set JAVA_HOME to JDK 17.

Q: CocoaPods error on iOS pod install

Solution: Navigate into ios/, remove Podfile.lock and Pods/ folder, then run pod repo update and pod install.

Q: Are both apps guaranteed to pass flutter analyze?

Solution: Yes! Both the Student App and the Instructor App pass flutter analyze with 0 errors and 0 warnings, fully compliant with CodeCanyon and Codester strict quality standards.
