5. Android Release Signing Configuration

Complete project-specific guide to generate a keystore and configure release signing for both applications.

1

Generate an Upload Keystore

Open terminal and execute the standard Java keytool command to create a private signing keystore:

Terminal (macOS / Linux)
keytool -genkey -v -keystore ~/upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
PowerShell (Windows)
keytool -genkey -v -keystore "$env:USERPROFILE\upload-keystore.jks" -keyalg RSA -keysize 2048 -validity 10000 -alias upload

Keep your keystore file, password, and alias safe! Google Play requires this same keystore for all future app updates.

2

Create android/key.properties

In the android/ directory of each app (Student_App/android/key.properties and Instructor_App/android/key.properties), create a new file named key.properties containing your credentials:

Properties (android/key.properties)
storePassword=YourKeystorePasswordHere
keyPassword=YourKeyPasswordHere
keyAlias=upload
storeFile=/Users/yourusername/upload-keystore.jks

Note for Windows: Use forward slashes in path (e.g. C:/Users/yourname/upload-keystore.jks).

3

Configure Student_App/android/app/build.gradle (Groovy DSL)

Update Student_App/android/app/build.gradle to load key.properties and bind it to the release buildType:

Groovy (Student_App/android/app/build.gradle)
import java.io.FileInputStream
import java.util.Properties

def keystoreProperties = new Properties()
def keystorePropertiesFile = rootProject.file('key.properties')
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}

android {
    ...
    signingConfigs {
        release {
            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
            storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
            storePassword keystoreProperties['storePassword']
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
            shrinkResources false
        }
    }
}
4

Configure Instructor_App/android/app/build.gradle.kts (Kotlin DSL)

Update Instructor_App/android/app/build.gradle.kts with the Kotlin DSL equivalent:

Kotlin (Instructor_App/android/app/build.gradle.kts)
import java.io.FileInputStream
import java.util.Properties

val keystoreProperties = Properties()
val keystorePropertiesFile = rootProject.file("key.properties")
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(FileInputStream(keystorePropertiesFile))
}

android {
    ...
    signingConfigs {
        create("release") {
            keyAlias = keystoreProperties.getProperty("keyAlias")
            keyPassword = keystoreProperties.getProperty("keyPassword")
            storeFile = keystoreProperties.getProperty("storeFile")?.let { file(it) }
            storePassword = keystoreProperties.getProperty("storePassword")
        }
    }

    buildTypes {
        release {
            signingConfig = signingConfigs.getByName("release")
        }
    }
}

Troubleshooting & FAQ

Solutions to the most common configuration and compilation queries.

Q: Gradle error: "Unsupported class file major version 65"

Solution: Ensure your system is using Java JDK 17. Run java -version in your terminal. If it shows JDK 21 or higher, install JDK 17 and configure your JAVA_HOME environment variable or set JDK 17 inside Android Studio (Settings → Build → Gradle → Gradle JDK).

Q: CocoaPods error on iOS: "Podfile: Failed to install"

Solution: Inside macOS terminal, navigate into ios/, delete Podfile.lock and the Pods/ folder, then run:

pod repo update && pod install

Q: How to run flutter analyze?

Solution: Run flutter analyze in either project directory. Both applications pass with 0 errors and 0 warnings, compliant with strict marketplace standards.

Q: What if my new icon doesn't update on my test phone?

Solution: Uninstall the older version of the app from your device/emulator first, run flutter clean, and re-run flutter run. Android and iOS heavily cache launcher icons.
